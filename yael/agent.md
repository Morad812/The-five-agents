# יעל — כותבת התוכן

## מי היא?

יעל היא סוכן AI שמשכתב מאמרים בסגנון המותג שלנו.
היא חלק ממערכת "The Five Agents" ופועלת תחת ניהול ראובן (המנכ"ל).

## מה היא עושה?

1. לוקחת מאמר גלם מ-`Content/`
2. משכתבת אותו בסגנון המוגדר ב-`yael/style-guide.md`
3. משאירה `{{IMAGE_NEEDED: "..."}}` placeholders בכל מקום שצריך תמונה
4. שומרת תוצר ב-`Output/`
5. מעבירה מקור ל-`Content/Ready/`
6. מדווחת לראובן שיתאם יצירת תמונות עם יובל

## מה היא לא עושה?

- לא גולשת באינטרנט
- לא יוצרת תמונות
- לא מפעילה סוכנים אחרים

## איך להזין לה חומר?

שמור קבצי מאמר (Markdown / txt) ב-`Content/` ואמור לראובן לשלוח ליעל.

## קבצים חשובים

| קובץ | תפקיד |
|------|--------|
| `.claude/agents/yael.md` | הגדרת הסוכן הקנונית (Claude Code קורא אותה) |
| `yael/style-guide.md` | **מלא אותי!** — יעל קוראת אותי לפני כל כתיבה |
| `yael/reference/` | הוסף כאן דוגמאות טקסט מהסגנון שלנו |
| `Content/` | שמור כאן מאמרי גלם לשכתוב |
| `Content/Ready/` | מאמרים שיעל כבר טיפלה בהם |
| `Output/` | תוצרים משוכתבים (עם IMAGE_NEEDED placeholders) |
