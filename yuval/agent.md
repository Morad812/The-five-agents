# yuval — Creative Image Agent

This directory is yuval's working space.

- **Agent definition:** `.claude/agents/yuval.md` — the canonical file Claude Code reads
- **Reference images:** `yuval/reference/` — add inspiration images here; yuval reads these to extract visual style before generating
- **Generated images:** `yuval/outputs/` — all outputs land here as `YYYY-MM-DD-<slug>.png` with a sibling `.txt` prompt log
